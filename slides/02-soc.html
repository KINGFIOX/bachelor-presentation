SoC 系统整体架构

分层总线架构：CPU 作为唯一 AXI4 Master 接入一级 Crossbar， 一级 Crossbar 下面只挂着 SDRAM 高速路径； MROM、SRAM 与 AXI4ToAPB 接入二级 Crossbar； XIP-Flash、PSRAM(QSPI/QPI)、UART 16550、GPIO、PS2、VGA、PLIC、CLINT 等低速设备统一进入 APB 域。

SoC 系统整体架构

三类速率域分离

SDRAM 不受慢设备干扰；MROM, PSRAM, SRAM仅作为；外设统一接入 ABP 域

统一 Diplomacy

基于 rocket-chip Diplomacy 框架进行参数协商，互连结构由 Chisel 元编程自动生成

多层次存储与启动链路

按"启动可靠性 → 访问延迟 → 容量"分工：MROM / SRAM / Flash / PSRAM / SDRAM 五层存储； 启动采用分级引导，避免直接从 XIP Flash 执行大体量程序，降低性能损失。
_start (MROM) -> FSBL (XIP Flash) -> SSBL (SDRAM) -> trm_init -> main / kernel

分级引导职责

  • _start负责设置栈顶地址、跳转到 fsbl
  • FSBL(first stage bootloader)将 SSBL 拷贝到 SDRAM
  • SSBL(second stage bootloader)将应用程序/内核从 Flash 拷贝到 SDRAM
  • trm_init(turing machine init)初始化外设、装载 mtvec、建立裸机运行时
  • main可以是裸机程序，也可以是 RT-Thread / xv6
