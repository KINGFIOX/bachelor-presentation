SoC 系统整体架构

分层总线架构：CPU 作为唯一 AXI4 Master 接入一级 Crossbar， 仅挂接 SDRAM 高带宽路径以最短化访存延迟； MROM、SRAM 与 AXI4ToAPB 桥经 Frag/Yanker 接入二级 Crossbar； XIP-Flash、PSRAM(QSPI)、UART 16550、GPIO、PS2、VGA、PLIC、CLINT 等低速设备统一进入 APB 域。

三类速率域分离

SDRAM 不受慢设备干扰；APB 实现简单；扩展新外设只需在 APB Fanout 增加地址映射

统一 Diplomacy

基于 rocket-chip Diplomacy 框架进行参数协商，互连结构由 Chisel 元编程自动生成

多层次存储与启动链路

按"启动可靠性 → 访问延迟 → 容量"分工：MROM / SRAM / Flash / PSRAM / SDRAM 五层存储； 启动采用分级引导避免直接从串行 Flash 执行大体量程序的性能损失。
_start → FSBL (XIP Flash) → SSBL (SDRAM) → trm_init → main / kernel

分级引导职责

  • FSBL（XIP Flash 中执行）：初始化 SP，将 SSBL 拷贝到 SDRAM
  • SSBL（SDRAM 中执行）：将应用程序/内核从 Flash 拷贝到 SDRAM
  • trm_init：初始化外设、装载 mtvec、建立裸机运行时
  • main：可以是裸机程序，也可以是 RT-Thread / xv6
