Flash 控制器与 XIP 机制

APB XIP 控制器状态转移图（8 态）

Flash 双访问模式：

  • 命令方式：经 APB → SPI Arbiter → SPI 寄存器，用于 Bootloader 阶段 Flash 编程
  • XIP 方式：CPU 对 Flash 地址窗口的 MMIO 读 → 自动转换为 SPI 命令字序列 → 直接取指
引入 XIP 的动机：避免"鸡生蛋"死锁——若程序在 Flash 中而访问 Flash 又依赖软件驱动， 则驱动本身需先从 Flash 取出，系统无法启动。XIP 提供硬件读通路，无需软件驱动即可启动。

基于 Winbond W25Q128JVSIQ 手册时序，实现行为级仿真模型并经类 UVM 验证，协议正确性可对接物理芯片。

PSRAM QSPI Master 控制器

使用 Chisel 重新实现完整 QSPI Master，APB 接口，支持标准 QSPI ↔ QPI（四线半双工）模式切换。

Shift

仿真模型

idle → cmd → addr → data → done
意义：与 SPI Flash 共用底层架构思路， 但 QPI 模式下吞吐率提升至 4×； 为 SDRAM 缺失时提供扩展主存路径。

SDRAM 控制器：Chisel 完整重写 + 字扩展

SystemC UVM 测试平台（基于 ultraembedded 重构）

Fork ultraembedded/core_sdram_axi4， 但使用 Chisel 完整重写，并新增位扩展与字扩展能力。

  • 位扩展：两颗 SDRAM 同步访问，将 16bit × 2 拼接为 32bit 数据通路
  • 字扩展（低位交叉）：两个 SDRAM Core 按 addr(2) 路由到奇/偶 Core，并发访问
  • 事务桥：SdramAxiPmem + Queues 解耦请求/响应通路；pendingQ 保证响应回传顺序
重写收益：利用 Chisel Queue 充分发挥 AXI4 的 outstanding 与乱序响应特性， 流水化程度显著优于原 Verilog 版本。

基于 Micron MT48LC16M16A2 行为级模型 + SystemC UVM 验证；可直接对接物理 SDRAM 颗粒。
