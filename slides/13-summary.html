主要工作与创新点

① 完整 SoC 与关键 IP 核全自研

AXI4/APB 分层互连；Flash (XIP)、PSRAM (QSPI)、SDRAM 控制器全部 Chisel 实现/重写，配行为级仿真模型并经协议级验证

② 单发射乱序处理器核心

RV64IM；前后端解耦 + 统一物理寄存器重命名 + ROB 顺序提交 ⇒ 精确异常；GShare + IJTC + RAS 组合分支预测

③ 完整 RISC-V 特权架构

M/S/U 三级特权 + 异常委托 + Sv39 三级页表（TLB + PTW）+ PLIC + CLINT，为 OS 提供完整体系结构支撑

④ Verilator + C++20 仿真验证平台

DiffTest 逐指令比对 + LightSSS fork 快照 + tracer + 缓存级差分

⑤ xv6 + RT-Thread 双 OS 验证

xv6 启动稳定运行用户态程序；RT-Thread 配合 NVBoard 完成多任务调度与外设可视化演示

⑥ 量化性能评估

RTL 寄存器 + DPI-C 事件混合性能计数器；MicroBench / Dhrystone / CoreMark 三组基准； Dhrystone 1.596 DMIPS/MHz ≈ Cortex-M3
