研究背景与课题目标

研究背景

  • 开源指令集架构 RISC-V 的快速发展
  • 乱序执行是现代处理器获得高性能的关键机制
  • 面向教学与工程实践需要可复现、可验证、可演化的 RISC-V 乱序处理器实现路径

课题目标

  • 使用 Chisel 设计并实现了 RV64IM 的 单发射乱序处理器
  • 构建包含自主设计 IP 核（Flash / PSRAM / SDRAM）的完整 SoC 系统
  • 实现 M/S/U 三级特权架构与 Sv39 虚拟内存， 支持运行 xv6 教学操作系统
  • 构建 Verilator + C++20 的仿真验证平台
本文工作交付：支持 RV64IM 的单发射乱序 RISC-V 处理器 + 完整 SoC + 仿真验证平台；成功运行 xv6 / RT-Thread； IPC 0.43–0.56，Dhrystone 0.559 DMIPS/MHz，CoreMark 1.540 CoreMark/MHz； 核心代码以 GPLv2 开源。
