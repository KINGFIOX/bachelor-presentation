xv6 验证了哪些硬件特性

  • M/S/U 三级特权切换：mret/sret 进入 S/U-mode，syscall 经 ecall 进入 S-mode
  • 异常委托：medeleg/mideleg 让 page fault 与 syscall 直接由 S-mode 处理
  • Sv39 虚拟内存：内核与用户空间隔离 / fork 时 copy-on-write 触发 page fault
  • 定时器中断：CLINT + stimecmp 驱动调度器轮转
  • 外部中断：PLIC + UART 16550 与 virtio-disk
  • fence.i / fence + DMA 一致性：virtio-disk 块传输
已成功启动并稳定运行：进入 init → 拉起 sh → ls / cat / forktest / usertests 全程通过。 乱序执行 + 缓存 + 异常 + 虚拟内存全链路验证。

RT-Thread 验证了多任务调度、上下文切换、定时器中断驱动的任务轮转， 以及对自研 GPIO/PS2/VGA/UART 控制器的 bare-metal 外设访问。
软件正确性验证策略：实现 Spike + NVBoard 模拟器 。 在尽量隔离硬件实现干扰的条件下，先验证软件逻辑与外设交互；再回归到 RTL 平台闭环验证。
